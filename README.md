# Volleyball Bot

Telegram-бот для еженедельных опросов «кто идёт на волейбол». В игровые дни
(вторник, четверг, пятница, воскресенье) бот создаёт опрос на тот же день
через неделю, закрепляет его и удаляет опросы возрастом 7 дней и старше.

## Настройка

1. Скопируйте `.env.example` в `.env` и заполните значения:

   ```env
   TELEGRAM_BOT_TOKEN=токен_из_@BotFather
   TELEGRAM_CHAT_ID=-100xxxxxxxxxx
   ```

2. Добавьте бота в группу и выдайте ему права администратора с возможностью
   **закреплять** и **удалять** сообщения — иначе закрепление и очистка старых
   опросов работать не будут.

## Запуск

```bash
go mod tidy
go run .
```

или сборка:

```bash
go build -o volleyball_bot .
./volleyball_bot
```

## Переменные окружения

| Переменная           | Описание                                                              |
|----------------------|----------------------------------------------------------------------|
| `TELEGRAM_BOT_TOKEN` | Токен бота из @BotFather (обязательно)                               |
| `TELEGRAM_CHAT_ID`   | ID чата/группы для опросов, для супергрупп с `-100` (обязательно)    |
| `STORE_PATH`         | Путь к файлу хранилища закрепов (опционально, по умолчанию `polls.json`) |
| `CRON_SCHEDULE`      | Cron-расписание проверки (опционально, по умолчанию `0 20 * * *`)    |
| `TIMEZONE`           | Таймзона планировщика и дат (опционально, по умолчанию `Europe/Moscow`) |
| `GAME_DAYS`          | Игровые дни через запятую, англ. названия (опционально, по умолчанию `Tuesday,Thursday,Friday,Sunday`) |

Переменные читаются из файла `.env` (если есть) или из реального окружения.

## Игровые дни

Дни, в которые бот создаёт опрос, задаются переменной `GAME_DAYS` —
англоязычные названия через запятую, регистр не важен, например
`GAME_DAYS="Tuesday,Thursday,Friday,Sunday"`. Чтобы добавить или убрать день,
достаточно изменить переменную окружения — править код не нужно.

## Расписание и таймзона

Расписание задаётся переменной `CRON_SCHEDULE` (по умолчанию `0 20 * * *` —
ежедневно в 20:00). Время считается в таймзоне `TIMEZONE` (по умолчанию
`Europe/Moscow`) **независимо от часового пояса сервера**, поэтому на UTC-сервере
опросы всё равно создаются по московскому времени. База таймзон встроена в бинарник
(`time/tzdata`), так что `LoadLocation` работает даже на минимальных образах.

## Структура проекта

```
main.go            точка сборки (wiring)
config/            загрузка конфигурации из env
storage/           репозиторий закрепов (polls.json)
poll/              бизнес-логика и домен (создание/удаление опросов, текст)
scheduler/         cron и graceful shutdown
```

## Хранилище опросов

Созданные закреплённые опросы сохраняются в `polls.json` рядом с ботом в виде
списка `{message_id, created_at}`. Bot API не позволяет получить список всех
закреплённых сообщений, поэтому файл используется как источник правды при
удалении старых опросов. Файл не коммитится (см. `.gitignore`).

## Логи

Логи пишутся в `stderr`. При запуске под systemd они попадают в `journald`
(`journalctl -u <service>`), под Docker — в `docker logs`, в консоли — в терминал.
